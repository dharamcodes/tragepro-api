# 🚀 Spring Java Project Prompt

This prompt serves as a standard workflow for Spring Boot projects using **Spring Data MongoDB** and other libraries.

---

## 1. [Develop Feature](ca://s?q=Develop_feature_in_Spring_Boot)
- Implement new functionality in the Spring Boot application.
- Use **Spring Data MongoDB** for persistence.
- Follow clean architecture and coding best practices.
- Ensure proper dependency injection and configuration.

---

## 2. [Create Test Cases](ca://s?q=Create_JUnit_test_cases_for_Spring_Boot)
- Write **JUnit 5** unit tests for service and repository layers.
- Add **integration tests** using Spring Boot Test framework.
- Mock external dependencies with **Mockito**.
- Ensure coverage for edge cases and error handling.

---

## 3. [Create Bruno Test Cases](ca://s?q=Create_Bruno_test_cases_for_APIs)
- Define API test cases in **Bruno**.
- Add requests to the **raw requests collection**.
- Validate response codes, payloads, and headers.
- Include both positive and negative scenarios.

---

## 4. [Run Everything](ca://s?q=Run_all_tests_in_Spring_Boot_project)
- Execute unit tests, integration tests, and Bruno API tests.
- Verify all services, endpoints, and database interactions.
- Ensure application builds successfully with **Maven/Gradle**.
- Confirm end-to-end functionality before deployment.

---

## ✅ Checklist
- [ ] Feature implemented
- [ ] Unit tests created
- [ ] Integration tests created
- [ ] Bruno test cases added
- [ ] All tests executed successfully
